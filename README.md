# 医疗客服知识沉淀案例 · 演示环境

一套**开箱可跑**的现场演示环境：从"开发 AI 写出缺陷"演到"知识沉淀后被复用"。
两段都有独立探针，读的是**实际发给模型的请求**，不是模型的自我声明。

## 这个仓库里有什么

| 目录 / 文件 | 内容 |
| --- | --- |
| `起始状态/` | 裸 Agent —— 演示起点（客服 Agent 最初形态，没有任何脱敏） |
| `材料/任务/` | 两段演示要发给开发 AI 的需求原文 |
| `材料/探针/` | 第一段 7 种写法探针；第二段通用/适配/原始三个探针；演示日期准备 |
| `材料/补丁/` | 第一段的修复补丁、第二段的实现参照 |
| `材料/知识/` | 两份知识文档（FormSy 正式 Server 提炼产物）、召回结果、人工评审意见、对照实验 |
| `材料/归档结果/` | 截至 2026-11-17 的历史实测 + 本机实测证据 |
| `环境/` | 隔离 CODEX_HOME 的检查与重建脚本 |
| `脚本/` | 分步脚本（跑 / 验 / 重置）、一条龙脚本 |
| `复现流程.md` | **完整流程**：开演前 → 两段 → 人工纠错 → 沉淀展示 → 收尾 → 故障 → 边界 |
| `结果/` | 跑出来的事件流与探针结果都落这里 |

## 快速开始

```sh
git clone https://github.com/FormSyAI/Formsy_Knowledge_Accumulation_demo.git
cd Formsy_Knowledge_Accumulation_demo
bash 部署.sh              # 展开两个工作区 + 生成隔离 CODEX_HOME
bash 环境/检查环境.sh      # 三项硬前提自检
open 复现流程.md           # 照着走
```

一条龙（两段真实模型会话，约 12–19 分钟）：

```sh
bash 脚本/跑完整流程.sh
```

## 三个必须知道的点

1. **模型通道**：只走本机 magpie 桥 + `tencent-cloud/deepseek-v4.1-flash`。换模型结果分布会变——
   实测 Codex 自带模型只漏 1/7，跟原始实验不是一个物种。
2. **凭据**：`部署.sh` 会从 `~/.codex/auth.json` 拷一份到 `环境/codex-home/`（权限 600，已被 `.gitignore` 忽略）。
   这个目录别上传、别打包外发。
3. **答案就在这个仓库里**：`材料/补丁/`、`材料/知识/`、`材料/归档结果/` 都带着"正确答案"。
   演示前把这三个目录挪到另一台机器或 U 盘，演示完再放回来——**工作区不依赖它们**，
   脚本只依赖 `材料/任务/` 和 `材料/探针/`。

## 结论边界（别讲过头）

- 第一段的缺陷是 **"做了，但没做全"**：开发 AI 会自己发现合规要求、主动加脱敏，
  但正则只认连续数字写法（实测漏 5/7）。**不要**讲成"AI 完全没想到要脱敏"。
- 两段都是**概率性**结果：截至 2026-11-17，第一段共 8 轮里 7 轮命中同一个根因；
  一次没复现不代表方法无效，一次复现也不代表必然。
- 第二段"没泄露"**不能单独证明**是知识起了作用；硬证据是 `材料/知识/对照实验/` 里
  强诱导场景的 8 对 8（给知识 0/8 泄露、不给知识 8/8 泄露）。
- 仓库内患者 / 手机号 / 证件号全部为**虚构合成数据**，不连任何真实医院系统。
